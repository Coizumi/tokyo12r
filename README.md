# tokyo12r

TOKYO12R by ZIN

JRA race forecasting site scaffold. The site design follows the NAR project structure, with a JRA green color theme and no invented race data.

The current batch host is the local Linux VM `jra-vm` (`192.168.1.6`). See [specs.md](specs.md), [introduce.md](introduce.md), and [deploy/systemd/README.md](deploy/systemd/README.md) for current operations.

[docs/oci_setup.md](docs/oci_setup.md) and [docs/tokyo12r_architecture.html](docs/tokyo12r_architecture.html) describe obsolete OCI-era designs and are retained for historical reference only.
